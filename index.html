COORDINATE CONSISTENCY
All U.S. ZIP Codes in a run use the same centroid dataset. Adding another ZIP will not replace the coordinates already being used for the other ZIP Codes.

Every non-selected ZIP must fall within 5 miles of a selected forecasting location under normal circumstances. ZIP Codes entered in the terrain / shoreline-sensitive field must fall within 2.5 miles of a selected location. Local knowledge should still be reviewed before final approval.
